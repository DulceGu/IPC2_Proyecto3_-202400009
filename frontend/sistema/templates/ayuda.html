Información del Estudiante

Guía Rápida del Sistema

Flujo de Trabajo Recomendado:

  1. Configuración Inicial: Cargar archivo XML con recursos, categorías y clientes
  2. Registro de Consumos: Cargar archivo XML con consumos de instancias
  3. Gestión de Datos: Usar operaciones del sistema para consultar y crear datos
  4. Facturación: Generar facturas por períodos de tiempo
  5. Reportes: Generar PDFs con detalles y análisis

Formatos XML Requeridos

Configuración del Sistema

Estructura para recursos, categorías, configuraciones, clientes e instancias:

<archivoConfiguraciones>
  <listaRecursos>
    <recurso id="1">
      <nombre>CPU Core</nombre>
      <abreviatura>CPU</abreviatura>
      <metrica>unidades</metrica>
      <tipo>Hardware</tipo>
      <valorXhora>1.20</valorXhora>
    </recurso>
  </listaRecursos>
  <listaCategorias>...</listaCategorias>
  <listaClientes>...</listaClientes>
</archivoConfiguraciones>

Consumos

Estructura para registro de consumos de instancias:

<listadoConsumos>
  <consumo nitCliente="12345-6" idInstancia="1">
    <tiempo>5.5</tiempo>
    <fechahora>15/10/2025 14:30</fechahora>
  </consumo>
</listadoConsumos>

Características del Sistema

  • Gestión completa de recursos cloud
  • Configuraciones por categorías
  • Registro de clientes e instancias
  • Seguimiento de consumos en tiempo real
  • Generación automática de facturas
  • Reportes detallados en PDF
  • Interfaz web moderna y responsive
  • API RESTful para integraciones
  • Validación de datos y formatos
  • Persistencia en archivos XML

Soporte Técnico

Problemas Comunes y Soluciones:

  • Error de conexión al backend: Verificar que el servidor Flask esté ejecutándose en puerto 4000
  • Archivo XML inválido: Revisar la estructura y sintaxis del XML
  • Datos no persisten: Verificar permisos de escritura en la carpeta data/
  • Facturas no generadas: Confirmar que existan consumos en el período seleccionado
